Every ad platform, analytics tool, and ecommerce system CleanClicks integrates with.

## Ad Platforms

| Platform | Connection | Click ID | Server-Side Method | Current public plan |
|---|---|---|---|---|
| **Google Ads** | OAuth | `gclid`, `wbraid`, `gbraid` | Enhanced Conversions and configured offline conversion paths | Signal or Clarity |
| **Meta** | Manual token | `fbclid` | Conversions API | Signal or Clarity |
| **TikTok** | Manual token | `ttclid` | Events API | Signal or Clarity |
| **Microsoft Ads** | OAuth | `msclkid` | Offline Conversions API | Signal or Clarity |

Signal can use any three of these four current ad destinations. Clarity can use all four. LinkedIn is not part of the current sellable destination set.

## Analytics Platforms

| Platform | Connection | Purpose | Current public plan |
|---|---|---|---|
| **GA4** | Measurement ID and supported API credentials | Analytics layer and supported event delivery | Signal or Clarity |
| **Usermaven** | Workspace API key and server token | Analytics layer and supported event delivery | Signal or Clarity |

GA4 and Usermaven do not use an ad-destination slot.

## Ecommerce Platforms

| Platform | Client-Side | Server-Side | Plugin/Pixel | Minimum Plan |
|---|---|---|---|---|
| **Shopify** | Custom Pixel (7 events) | Webhook (purchase) | Shopify Custom Pixel | Signal or Clarity |
| **WooCommerce** | WordPress plugin (6 events) | Supported browser and server order paths | CleanClicks WP Plugin v1.11.0 | Signal or Clarity |

## External Integrations (Inbound Webhook)

CleanClicks accepts conversion data from any external system via the inbound webhook API:

- **CRMs:** HubSpot, Salesforce, Pipedrive, etc.
- **Automation tools:** Zapier, Make.com, n8n, ActivePieces
- **Custom backends:** Any system that can make HTTP POST requests
- **Call tracking:** CallRail, CallTrackingMetrics, etc.

See [Inbound Webhooks](/guides/inbound-webhooks) for the API reference.

## Client-Side Event Bridges

For iframe-based platforms (booking widgets, scheduling tools, embedded forms), CleanClicks supports event capture via the browser's `postMessage` API. Configure allowed origins and event mappings in Configuration > Advanced.

## Data Handling

| Data Type | How It's Handled |
|---|---|
| Customer email | SHA-256 hashed before sending to ad platforms |
| Click IDs | Stored in first-party cookies, attached to conversions |
| UTM parameters | Stored in first-party cookies, included in all events |
| IP addresses | Used for geo-enrichment, never stored long-term |
| Conversion data | Retained for 90 days |
| Session data | Retained for 90 days |
