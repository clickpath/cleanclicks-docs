Ecommerce tracking enables server-side order capture from Shopify and WooCommerce. Available on **Signal** plans and above.

## Accessing Ecommerce Settings

1. Go to **Configuration** in the sidebar
2. Select your domain
3. Click the **Ecommerce** tab

Ecommerce support is part of the current Signal and Clarity plans.

## Shopify Integration

### Webhook Setup

CleanClicks uses a Shopify webhook as one server-side order path. Webhook delivery, identifiers, deduplication, destination configuration, and an accepted receipt still determine whether the purchase path is complete.

The Ecommerce tab provides:
- **Webhook URL** — copy this into Shopify
- **Webhook Secret** — used for secure verification

To configure in Shopify:
1. Go to Shopify Admin > **Settings** > **Notifications** > **Webhooks**
2. Click **Create Webhook**
3. Event: **Order payment**
4. Format: **JSON**
5. URL: paste the webhook URL from CleanClicks
6. Click **Save**

### Custom Pixel

Shopify also needs the client-side Custom Pixel for capturing browsing events (page views, product views, cart actions). See [Shopify Setup](/setup/shopify-setup) for pixel installation.

The browser and webhook paths work together to improve purchase coverage. Verify the installed pixel or plugin, webhook, event ID, order ID, and destination receipt before treating a purchase path as accepted.

## WooCommerce Integration

### WordPress Plugin

The CleanClicks WordPress plugin handles both client-side event tracking and server-side conversion capture. Install the plugin and the rest is automatic.

See [WordPress Setup](/setup/wordpress-setup) for the full plugin reference. Quick summary:

1. Download the plugin from this Ecommerce tab
2. Upload + activate in WordPress
3. Enter your Inbound API Key (from **Configuration** → **Inbound keys** tab) in **Settings** → **CleanClicks** → save

### Server-Side Webhook (Automatic)

On activation, the plugin auto-creates a WooCommerce `order.created` webhook pointed at your CleanClicks proxy, signed with your Inbound API Key. **No manual webhook configuration required.**

Verify it in WordPress Admin → **WooCommerce** → **Settings** → **Advanced** → **Webhooks** — look for "CleanClicks Conversion Capture."

The plugin layers two additional server-side capture paths on top of the standard webhook: a `woocommerce_payment_complete` hook for subscription renewals and offsite checkout returns, and a configurable `purchase_paths` allowlist for custom thank-you pages. See [WordPress Setup → Server-Side Conversion Capture](/setup/wordpress-setup#server-side-conversion-capture) for the full three-layer reference.

### Webhook Status

The plugin settings page shows a live Webhook Status card. If the auto-created webhook is ever missing or in an error state, the card surfaces the reason and offers a **Recreate Webhook** button.

## Plugin Download

The Ecommerce tab includes a download link for the CleanClicks WordPress plugin. This is the same plugin described in [WordPress Setup](/setup/wordpress-setup).

## What Gets Tracked

Both Shopify and WooCommerce integrations capture:

| Data Point | Description |
|---|---|
| Order ID | Your store's order identifier |
| Order total | Revenue amount |
| Currency | Transaction currency |
| Tax and shipping | Order tax and shipping amounts, reported to Google Analytics. On Shopify: with pixel version 2.8.0 or later, or with an earlier version only when the pixel itself reports the purchase to Google Analytics |
| Coupon codes | Codes applied to a cart or an order (WooCommerce only), reported to Google Analytics |
| Products | Product names, IDs, quantities, prices |
| Customer email | Hashed for privacy, used for cross-platform matching |
| Click IDs | gclid, fbclid, etc. for attribution |
| UTM parameters | Campaign attribution data |

These are the main fields. An order message from your store's server can contain more than this table lists.

Customer emails are SHA-256 hashed before being sent to ad platforms. In what CleanClicks's servers build and send, only the SHA-256 hash is passed on, apart from an email address inside an advertising click-identifier value. The first-party analytics proxy does not screen the page addresses in your site's own Google tag requests, so an email address your site puts into a page address can reach Google that way.

Beyond the purchase, the Shopify Custom Pixel and the WooCommerce plugin also capture the browsing funnel — `view_item`, `add_to_cart`, and `begin_checkout` — and pass those to GA4, Meta, and TikTok under each platform's standard event names.

## Attribution

A webhook order arrives with no browser session attached to it. CleanClicks looks the visitor up by hashed email and recovers:

- Click IDs from the ad platforms (gclid, fbclid, and the rest)
- UTM parameters from the original visit
- The GA4 client ID and session ID
- The Usermaven anonymous ID

Recovery needs that visitor's hashed email to have been captured earlier in the visit. Without it there is nothing to match the order against, and the conversion goes out carrying only what the webhook itself brought. CleanClicks does not transmit to advertising platforms a conversion from an order it can tie to an opt-out, and of the analytics events CleanClicks's servers build and send, nothing is sent for it unless a measurement-only setting has been switched on for that destination and the visitor's refusal is known not to cover analytics. An order that a Shopify store reports from its own servers does not carry a Global Privacy Control signal or the opt-out cookie from the visitor's browser. See the CleanClicks privacy policy (Section 4).

Coverage also depends on capture timing, consent state, deduplication, webhook delivery, and whether the destination accepts the event.
